## Overview:
	- Resource Groups - logical containers for resources
	- All deployed resources are part of a single resource group, but can be moved later on between RGs
	- Resources in an RG cam be deployed to different regions
	- RGs are better to manage and organize resources

Resources can be in different regions, but RGs are tied to a specific region - metadata of resources has to be stored in a location

## Organization:
	- By Environment
	- By Resource Type
	- By Department
	- By Admin Type
	- By Lifecycle
	- By Billing Reports
