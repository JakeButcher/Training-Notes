## Overview:
	- Several tools for better team collaboration
	- Suite of services that provide solutions

## Tools:
	- Azure Boards - Agile tools to help plan, track and discuss work
	- Azure Pipelines - build, test and deploy with CI/CD that work in any language / platform
	- Azure Test Plans - manual and explanatory testing tools
	- Azure Repos - unlimited cloud-hosted private and public Git repos
	- Azure Artifacts - create, host and share packages

## DevTest Labs:
	- Enables developers to self-manage VMs and PaaS resources without waiting for approvals
	- Can create labs consisting of pre-configured resources
	- Easily test the latest versions of applications and speed up the process of creating / terminating test environments
