## SQL Data Warehouse:
	- Can use to run complex queries across petabytes of data
	- Import data to SQL Data Warehouse and run high-performance Analytics, leveraging massively parallel processing (MPP)
	- Businesses rely on insights to drive in the right direction
	
## Azure Databricks:
	- An Apache Spark-based analytics platform optimized for Azure Cloud platform
	- Analyze data and generate insights
	- Data from
		○ SQL Data Warehouse
		○ Azure Blob Storage
		○ Azure Data Lake Storage
		○ Azure Cosmos DB

## Azure HD Insight:
	- Cost-Effective enterprise-grade service for open-source analytics
	- Run popular open-source frameworks, including Apache Hadoop, Spark and Kafka
	- Process massive amounts of data
	- Integrates with other Azure Services (like Data Factory and DLS)
