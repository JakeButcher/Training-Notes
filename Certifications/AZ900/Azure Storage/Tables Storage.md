## NoSQL Structured Data:
	- Service that stores structured NoSQL Data in the cloud
	- Known as NoSQL datastore; ideal for structured, non-relational data
	- Azure managed service - tables will scale as demand increases

## Benefits:
	- Highly scalable, very cheap service for Serverless apps
	- Stores structured data in the cloud, providing a key/attribute store with schema-less design
	- Key/attribute <-> Tags (name/value)
	- Schema-less DB doesn’t have fixed structure
