## Managed File Share
	- Files that can be managed in the cloud, accessible via SMB Protocol
	- Can be attached by both On-Prem / VMs
	- Can mount a storage share to access file data



## Benefits:
	- Traditional file servers can be replaced and additional capacity added
		○ Mounted from any location
		○ Working on Win, Mac and Linux
	- Lift and Shift Apps
		○ Both app and data stored in Azure
		○ App on-prem and data in Azure Files
	- PnP compatibility - SMB protocol
	- Managed Service
	- Automate Work
		○ Multiple tools available for scripting
		○ Azure CLI / PS
	- Always-on File Share
		○ High Availability / Scalability
		○ No maintenance windows planned / unplanned
