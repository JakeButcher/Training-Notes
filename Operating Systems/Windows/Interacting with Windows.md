## Beyond the traditional mouse and keyboard, Windows supports various interaction methods:
	• Touch Input: For devices with touchscreens, enabling gestures and direct manipulation.
	• Pen Input: For digital pens, allowing drawing, writing, and annotation.
	• Voice Control (Cortana/Windows Voice Recognition): For hands-free interaction and commands.

## Command Line Interfaces:
	• Command Prompt (CMD.exe): The traditional command-line interpreter, still useful for many basic tasks.
	• Windows PowerShell: A powerful object-oriented command-line shell and scripting language, built on the .NET Framework, offering advanced system administration and automation capabilities.
	• Windows Terminal: A modern host for command-line interfaces, providing a more customizable and feature-rich experience.
