A document library is a secure location to store files where users can find them easily, collaborate, and access them from any device at any time. For example, a document library can be used on a site in SharePoint to store all files related to a specific project or a specific client. Adding files or moving files between folders is as easy as dragging and dropping them from one location to another.

SharePoint Server 2019 includes a document library and one is created automatically when you create a new site by default. New libraries can be created, and user access can be adjusted. Each document library displays a list of files, folders, and key information about each, such as who created or last modified a file. You can use this information to organize your files and make it easier to find them.
