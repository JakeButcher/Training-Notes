## Overview:
	- Use Azure Credits
		○ Visual Studio subscribers receive a monthly credit oin Azure
		○ $50/$150 credit to use for testing in Azure
	- Use spending limits
		○ Specific to subscriptions with monthly credit
		○ Services disabled/turned off until next period
	- Use Reserved Instances
		○ For long term VM usage (1y/3y) reserving capacity in advance brings discounts up to 72%
	- Use low-cost locations and regions
		○ Cost of Azure resources vary between regions and locations
	- Resize underutilized VMs
		○ Over-sized VMs area common unnecessary expense
	- Run VM only when needed
	- Deleted unused VMs
	- Change cloud deployment model
		○ Where applicable, migrate to PaaS (vs IaaS) it's cheaper
	- Linux vs Windows
		○ Evaluate the price when initiating the VM
	- Reuse Windows Server Licenses
	- Reuse SQL Server Licenses
	- Use Dev/Test Subscription Offers
	- Use SQL Server Developer Edition
	- Use dedicated VM types for DBs
		○ Low vCPU, cost reduction on compute
