## Overview:
	- ATP (Azure Advanced Threat Protection) is cloud based security solution that identifies, protects and helps with investigation of advanced threats, compromised identities and malicious actions
		○ Can detect known malicious attacks, security issues and risks against the network
		○ Includes several components: ATP Portal, ATP Sensor, ATP Cloud Service
			§ ATP Sensors - Sensors installed directly on Domain Controllers
			§ ATP Portal - view data received by ATP Sensors / Monitor, Manage and Investigate threats in your network
			§ ATP Cloud Service - The actual cloud service that runs on Azure
		
		
	- AIP (Azure Information Protection) is a cloud based solution that helps organizations to classify and optionally, protect its documents and emails by applying labels
		○ Documents and emails are applied labels, depending on information stored
		○ Admin can define rules to detect sensitive data and labels will apply automatically
		○ After content is classified (and optionally protected), you can track and control how it is used
		○ Azure Rights Mgmt - Encryption and Authorization policies
