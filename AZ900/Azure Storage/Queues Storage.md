## Messaging Store:
	- Service for storing large numbers of messages, accessible from anywhere
	- Reliable messaging between application components
	- When app components are de-coupled, they can scale independently; queue storage provides asynchronous message queueing for communication between components

Queue - container of messages
Message - data in any format
Independent queues, separate business purpose
