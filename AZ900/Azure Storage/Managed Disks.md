	- Block-level storage volumes managed by Azure
	- Azure manages the storage account, stored as *.VHD file
	- Need to specify the disk size, type and provisioning

## Disk Roles:
	- OS Disk (win / linux)
	- Temp Disk
	- Data Disk


## Why Managed Disks?
	- Highly available and durable
	- Deploy VMs and simple/highly scale
	- Fully integrated with availability sets / zones
	- Granular access control

## OS Disk:
	- Pre-Installed OS

## Temp Disk:
	- Short Term Storage
	- Data persists a VM reboot
	- Power off - data is lost

## Data Disk:
	- Persistent Data
