## Introduction:
	- Microsoft's globally distributed, multi-model DB Service
	- Designed for high scale, global replication, low latency DBs
	- Document DB
		○ Document format JSON

# Key Features:
	- Global Distribution
	- 56+ regions
	- High Availability
	- Elastic Scale
	- Low latency guarentee
	- No Schema or index management
		○ Just operate on documents, which can have different properties / formats
	- Multiple API's 
		○ SQL (core API)
		○ Cassandra
		○ MongoDB
		○ Gremlin
		○ Azure Table Storage
