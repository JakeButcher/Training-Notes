## Overview:
	- General purpose relational DBaaS based on the latest stable version of SQL DB Engine
	- Provided as a Managed Service, highly available and high performance

	Deployment Models:
	- Single
		○ Fully managed, isolated DB
	- Elastic Pool
		○ Collection of Singal DB with shared resources
	- Managed Instance
		○ Fully managed instance of SQL Server
		○ Full SQL server capabilities

## SQL Server vs SQL Database:
	- SQL DB Server is the central admin point for single or multiple-pooled databases
	- Similar to on-prem traditional SQL

## Purchasing Options:
	- 3 pricing models
		○ Db Transaction Unit (DTU)
		○ Virtual Core (vCore) 
		○ Serverless model - vCore based
	- With DTU, you scale storage with compute at the same time; with vCore you can scale storage independently from  compute
	- Any existing SQL license can be used with vCore model
