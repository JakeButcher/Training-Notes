## Overview:
	- Azure Internet of Things (IoT) is a collection of managed cloud services that connect, monitor, and control billions of IoT assets
	- IoT devices communicate with one or more back-end services hosted in Azure Cloud
		○ IoT device typically made of a circuit board, with sensors attached, connected to the internet
	
## IoT Hub:
	- Managed Service that acts as a central message hub for bi-directional communication between IoT application and devices
	- IoT Central allows custom, cloud-hosted IoT solution
		○ Cloud-based application that receives data from a device and enables management of the device
		○ IoT devices connected to Cloud-Based application
