## Overview:
	-  Covers a broad range of networking capabilities
	- Provides key capabilities:
		○ Connectivity Services - vNET, ExpressRoute, VPN gateway
		○ Application Protection Services - DDoS protection, Firewall, NSGs, WAF, etc.
	- Application Delivery Services
		○ CDN, Load Balancer, Application Gateway
	- Network Monitoring
		○ Azure Monitor, Azure Service Health, Network Watcher, etc.

## Virtual Network:
	- Fundamental building block for private network in Azure (Private DC)
	- 2 vNETs communicate via vNET Peering
	- Communicate inbound via load balancer
	- Connect On-Prem network to a vNET using VPN Gateway or ExpressRoute

## Application Delivery Services:
	- Content Delivery Network (CDN) delivers high-bandwidth content to users by caching content at  physical nodes
	- Application Gateway - Web Traffic load balancer that enables you to manage traffic to web applications
