## Azure Monitor Overview:
	- Collects, Analyzes and Acts on telemetry from cloud and on-prem environments
	- Allows you to understand how apps are performing and proactively identify issues
	- Will monitor cloud environments and perform different functions such as analyzing, alerting, and streaming to external systems

## Azure Monitor Use Cases:
	- Create smart alerts and automated actions
	- Monitor resources and drill into monitoring data with Azure Log Analysis
	- Detect and diagnose issues across multiple applications with Azure Insights
	- Create  Visualizations with Azure Dashboards

## Azure Service Health Overview:
	- Combination of 3 separate services
		○ Azure status
		○ Azure service health
		○ Azure resource health
	- Azure Status informs of service outages in Azure, on a globally accessible page
	- Azure Service Health provides a personalized view of the health services in your regions, and can have alerts configured
	- Azure Resource Health provides information of your individual cloud resources, and can have alerts configured
