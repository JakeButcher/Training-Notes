## Overview:
	- Enables Cloud Architects to define a repeatable set of Azure Resources that implements and follows an organizations standards
	- A declarative way to orchestrate the deployment of various resource templates and other artifcats
		○ Role Assignments
		○ Policy Assignments
		○ ARM Templates
		○ Resource Groups
	- Deploy and update cloud environments in a repeatable manner, and using composable artifacts
	- Different to ARM Templates
		○ With ARM Templates, you execute the deployment, but once deployed, resources have no active connection/relationship to the template

## Blueprints Benefits:
	- Relationship with deployed resources is preserved
		○ Good for tracking and auditing
	- Can upgrade several subscriptions at once
	- Can use multiple templates
